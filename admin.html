Connect your database

The admin dashboard needs your Supabase project before anyone can log in.

  1. Create a free project at supabase.com (choose the Singapore region).
  2. Open SQL Editor, paste everything from supabase-setup.sql and press Run.
  3. Go to Project Settings → API Keys and copy the Publishable key (starts with sb_publishable_). Copy the Project URL from Project Settings → Data API.
  4. Paste them into supabase-config.js and upload it next to this page.

You pasted a secret key (sb_secret_…). Never put that in a website file: replace it with the publishable key, and in Supabase rotate the secret key (⋮ → Roll / Delete) to be safe.

Full step-by-step instructions are in ADMIN-SETUP.md.

Add another admin

  1. In Supabase, open Authentication → Users → Add user and create their login (email + password).
  2. Open SQL Editor, paste the line below with their email, and press Run.
insert into public.admins (user_id, email) select id, email from auth.users where email = 'their-email@example.com' on conflict do nothing;
